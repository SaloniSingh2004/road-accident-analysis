# 🚗 Road Accident Data Analysis & Dashboard

An end-to-end exploratory data analysis and interactive Excel dashboard analyzing road traffic accidents, casualty severity, and environmental factors.

---

## 📌 Project Overview
This project provides actionable insights into road safety by analyzing historical accident records across various conditions, vehicle types, and locations. 

The dashboard enables stakeholders to track key performance indicators (KPIs), identify high-risk road conditions, and understand trends across urban vs. rural environments.

---

## 📊 Key KPIs & Metrics Tracked
* **Total Casualties & Accidents**: Aggregation by severity (Fatal, Serious, Slight).
* **Temporal Trends**: Monthly and day-of-week distribution of accidents.
* **Environmental Impact**: Analysis based on weather, light conditions, and road surface (Dry, Wet, Ice).
* **Infrastructure Factors**: Casualties across road types (Single carriageway, Roundabout, One-way) and speed limits.
* **Vehicle Breakdown**: Distribution across cars, private taxis, motorcycles, and commercial vehicles.

---

## 🛠️ Tools & Techniques Used
* **Microsoft Excel**: Data cleaning, Pivot Tables, Pivot Charts, Slicers, and Interactive Dashboard Design.
* **Data Modeling**: Categorization of accident severity and casualty distributions.
